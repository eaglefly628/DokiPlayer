# DokiPlayer 评分标准

标准版本：0.2.0。所有分项为0–100分。借鉴游戏媒体评测视角，针对AI叙事游戏作适配，不代表GameStar官方评分规则。

| 维度 | 关注问题 | 主要证据 |
|---|---|---|
| 美术与图像 | 风格、构图、角色与场景一致性、物件可辨识度 | 实际画面 |
| UI与操作布局 | 信息层级、物件/按钮布局、点击区域、遮挡、状态反馈 | 截图与实际操作 |
| 音乐、音效与配音 | 氛围、重复、情境匹配、语音质量、音量与反馈 | 实际听到的音频；没有听到则证据不足 |
| 剧情与逻辑 | 因果、设定、目标、时间、线索与结果一致性 | 前后剧情及状态变化 |
| 人物与对白 | 动机、语言、角色差异、记忆、回应是否切题 | 多轮对话及行为 |
| 氛围与沉浸 | 图像、声音、文字与世界规则是否协同 | 多模态观察；不重复当成某一项的独立缺陷扣分 |
| 核心玩法与选择 | 行动是否有意义、选择差异、解法、反馈、玩家自主性 | 真实行动和结算，不推断未访问分支 |
| 探索与任务设计 | 目标引导、地图路线、线索、前置与支线 | 地点、任务和资源记录 |
| 战斗与策略 | 战斗反馈、敌我差异、技能组合、检定风险 | 实际战斗；故事无此机制则不适用 |
| 成长、资源与平衡 | 奖励、消耗、难度曲线、失败代价、成长价值 | 行动前后状态与多次样本 |
| 节奏与持续吸引力 | 推进、悬念、重复、等待、是否愿意继续 | 本次体验判断；不冒充真实用户留存率 |
| 内容、收束与重玩价值 | 完成度、结局收束、内容重复和已验证分支 | 完成/多路线证据；未到结局不评收束 |
| 技术可靠性与恢复 | 卡住、超时、生成失败、降级、存档和恢复 | 错误、等待、恢复与重复验证 |

0分代表有证据支持的极差表现，不能代表没体验。分段锚点：0–19基本失效；20–39严重问题；40–59明显缺陷；60–74基本成立；75–89表现良好；90–100持续优秀且证据充分。美术与吸引力允许主观判断，但要写具体依据。

分项保留“已评分 / 证据不足 / 不适用”状态。当前不强行计算统一总分，避免探索短片段后制造虚假精度。每个问题标记归因：故事、框架或混合/未确认；画面与交互尤其可能同时涉及故事素材和引擎呈现。

参考：GameStar于2015年公开的[评分说明](https://www.gamestar.de/artikel/das-neue-wertungssystem-so-werten-gamestar-und-gamepro,3084841,seite2.html)列出表现、游戏设计、氛围/故事、平衡和内容量等分类。这里只借鉴观察角度，不称作其当前官方评分体系。
